# Measurements for 0.5

Built with `--release` in the build image on the build host (Linux x64, 24 cores); `version` the median of 30 runs.

| what | 0.4 | 0.5 |
|---|---|---|
| the static Linux binary (x64, musl) | 12.6 MB | 18.3 MB |
| the static Linux binary (arm64, musl) | | 16.1 MB |
| the Windows binary (x64, MinGW) | | 17.6 MB |
| `code-arena version` | 1.9 ms | 2.9 ms |
| the IDE's page built in (`web/dist`) | | 5.6 MB |
| Agent mode's code, loaded first | | 45 KB |
| Coder mode's code (Monaco, xterm), loaded when first opened | | 4.4 MB |

The binaries grew by the IDE's page, which each carries whole (Monaco is most of it); Agent mode loads only its
own 45 KB. `version` is a millisecond slower with the larger binary to map; the session store's figures are as 0.4's.

The arm64 and Windows binaries were built here but not run here: this host has neither an arm64 machine nor
Windows, and no emulator.
