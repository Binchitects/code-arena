# Measurements for 0.1

On the build host (Linux x64, 24 cores), the static `linux-x64` binary of each, run with an empty
`CODE_ARENA_HOME` so no settings are read. The C# figures are from a copy of Arena 8.1's
`dist/code-arena/linux-x64/code-arena`.

| | Code Arena 0.1 (Rust) | Code Arena 8.1 (C#) |
|---|---|---|
| the program | 7.1 MB (static, musl) | 48.8 MB (self-contained .NET) |
| the package (`.tar.gz`) | 3.2 MB | |
| `--version`, median of 30 runs (C#: 10) | 0.4 ms | 106 ms |
| memory for `--version` (max RSS) | 2.0 MB | 82.8 MB |

The plan's target for `--version` is 15 ms or less. Long-session figures come with sessions, in 0.2
and 0.4.

How: `python3` timing `subprocess.run([binary, "--version"])` in a loop, and `/usr/bin/time -v` for
the resident set size.
