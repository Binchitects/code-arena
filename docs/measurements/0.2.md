# Measurements for 0.2

The session store on a long session: 10,000 messages (2,500 turns of a question, a tool call, a
2,000-character result and an answer), one compaction, in a file on disk. Built with
`--release` in the build image on the build host (Linux x64, 24 cores); each figure the median of
20 runs. Run it with `cargo run --release -p ca-session --example measure`.

| what | 0.2 | the plan's target |
|---|---|---|
| append a message, on disk before the turn goes on | 0.35 ms | |
| open the store and read the last 30 turns | 1.25 ms | ≤ 30 ms |
| read the 30 turns before those (scrolling up) | 0.75 ms | |
| what the model reads (from the last compaction) | 1.54 ms | |
| search the folder's sessions (FTS5) | 7.6 ms | |
| the store on disk | 23 MB | |

The C# 8.1 version reads a session's JSON Lines file from its last compaction and pages its
turns for the IDE (366 KB in place of 1.5 MB for 500 messages, its manual says); it has no figure
for opening a session to compare with. The IDE's paint and scroll figures come with the IDE, in 0.4.
